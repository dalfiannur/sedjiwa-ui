# Combobox Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `<Combobox>` — a searchable, optionally-multiple, optionally-async select primitive — per `docs/superpowers/specs/2026-05-20-combobox-design.md`.

**Architecture:** Composite primitive on top of the existing `Popover`. The exported `Combobox` owns value / search / open state and renders the field-surface-styled trigger; an internal `ComboboxListbox` is the pure presentational popover content (search input, options, IntersectionObserver sentinel, ARIA wiring, keyboard handling).

**Tech Stack:** React 19, TypeScript, Radix Popover, TailwindCSS v4, `class-variance-authority` (via existing `fieldSurfaceVariants`), Vitest + Testing Library, Storybook 10.

---

## File Structure

| Path | Responsibility |
|---|---|
| `src/components/combobox/combobox.tsx` | Public `Combobox` component. Owns value/open/search state. Renders trigger button + chips, composes `Popover`. |
| `src/components/combobox/combobox-listbox.tsx` | Internal. Pure presentational popover body: search input, option rows, sentinel, empty / loading rows, ARIA roles. |
| `src/components/combobox/combobox.types.ts` | Discriminated-union `ComboboxProps<T>` and shared helper types. |
| `src/components/combobox/combobox.test.tsx` | Vitest + RTL tests for behavior, keyboard, ARIA, RHF integration. |
| `src/components/combobox/combobox.stories.tsx` | Storybook stories (also runs as Storybook-Playwright tests). |
| `src/components/combobox/index.ts` | Re-exports `Combobox` + `ComboboxProps`. |
| `src/index.ts` (modify) | Add `Combobox` to the library's public exports. |
| `package.json` (modify in final task) | Bump version to `0.10.0`. |

The component is split into `combobox.tsx` + `combobox-listbox.tsx` rather than one big file because keeping the listbox pure (no state ownership) is the only way the keyboard / search / pagination logic stays tractable.

```tsx
import * as React from "react";
import { ChevronDown } from "lucide-react";
import { cn } from "../../lib/cn";
import { fieldSurfaceVariants } from "../../lib/field-surface.variants";
import { Popover, PopoverContent, PopoverTrigger } from "../popover";
import { ComboboxListbox } from "./combobox-listbox";
import type { ComboboxProps } from "./combobox.types";

const DEFAULT_PLACEHOLDER = "Select…";

function ComboboxImpl<T>(
  props: ComboboxProps<T>,
  ref: React.ForwardedRef<HTMLButtonElement>,
) {
  const {
    placeholder = DEFAULT_PLACEHOLDER,
    size = "default",
    state = "default",
    disabled = false,
    className,
    id,
    "aria-label": ariaLabel,
  } = props;

  const [open, setOpen] = React.useState(false);
  const listboxId = React.useId();

  return (
    <Popover open={open} onOpenChange={disabled ? undefined : setOpen}>
      <PopoverTrigger
        ref={ref}
        id={id}
        type="button"
        role="combobox"
        aria-haspopup="listbox"
        aria-expanded={open}
        aria-controls={listboxId}
        aria-label={ariaLabel ?? placeholder}
        disabled={disabled}
        data-slot="combobox-trigger"
        data-state={state}
        className={cn(
          fieldSurfaceVariants({ size, state }),
          "items-center justify-between gap-2 px-3 text-left",
          "text-muted-foreground",
          className,
        )}
      >
        <span className="flex-1 truncate text-sm">{placeholder}</span>
        <ChevronDown
          aria-hidden="true"
          className="size-4 shrink-0 text-muted-foreground"
        />
      </PopoverTrigger>
      <PopoverContent
        align="start"
        sideOffset={4}
        className="w-(--radix-popover-trigger-width) min-w-60 p-0"
        onCloseAutoFocus={(e) => e.preventDefault()}
      >
        <ComboboxListbox listboxId={listboxId} />
      </PopoverContent>
    </Popover>
  );
}

export const Combobox = React.forwardRef(ComboboxImpl) as <T>(
  props: ComboboxProps<T> & { ref?: React.Ref<HTMLButtonElement> },
) => ReturnType<typeof ComboboxImpl>;
```

```tsx
import { cn } from "../../lib/cn";
import type { ComboboxOptionRenderState } from "./combobox.types";

export type ComboboxListboxItem<T> = {
  option: T;
  value: string;
  label: string;
  selected: boolean;
  disabled: boolean;
};

export type ComboboxListboxProps<T> = {
  listboxId: string;
  multiple: boolean;
  items: ComboboxListboxItem<T>[];
  emptyMessage: React.ReactNode;
  activeIndex: number;
  onSelectIndex: (index: number) => void;
  optionIdPrefix: string;
  renderOption?: (
    option: T,
    state: ComboboxOptionRenderState,
  ) => React.ReactNode;
  className?: string;
};

export function ComboboxListbox<T>({
  listboxId,
  multiple,
  items,
  emptyMessage,
  activeIndex,
  onSelectIndex,
  optionIdPrefix,
  renderOption,
  className,
}: ComboboxListboxProps<T>) {
  return (
    <div
      data-slot="combobox-listbox-root"
      className={cn("flex flex-col", className)}
    >
      <ul
        id={listboxId}
        role="listbox"
        aria-multiselectable={multiple || undefined}
        data-slot="combobox-listbox"
        className="max-h-60 overflow-y-auto p-1"
      >
        {items.length === 0 ? (
          <li
            data-slot="combobox-empty"
            className="px-2 py-1.5 text-sm text-muted-foreground"
          >
            {emptyMessage}
          </li>
        ) : (
          items.map((item, index) => {
            const active = index === activeIndex;
            return (
              <li
                key={item.value}
                id={`${optionIdPrefix}-${index}`}
                role="option"
                aria-selected={item.selected}
                aria-disabled={item.disabled || undefined}
                data-slot="combobox-option"
                data-active={active || undefined}
                data-selected={item.selected || undefined}
                data-disabled={item.disabled || undefined}
                onMouseDown={(e) => {
                  // Prevent the search input (in a later task) from losing focus.
                  e.preventDefault();
                }}
                onClick={() => {
                  if (!item.disabled) onSelectIndex(index);
                }}
                className={cn(
                  "relative flex w-full cursor-default items-center gap-2 rounded-sm py-1.5 pr-8 pl-2 text-sm select-none",
                  "outline-none",
                  active && "bg-accent text-accent-foreground",
                  item.disabled && "pointer-events-none opacity-50",
                )}
              >
                {renderOption ? (
                  renderOption(item.option, {
                    selected: item.selected,
                    active,
                  })
                ) : (
                  <span className="flex-1 truncate">{item.label}</span>
                )}
                {item.selected ? (
                  <span className="absolute right-2 flex size-3.5 items-center justify-center">
                    <Check className="size-4" />
                  </span>
                ) : null}
              </li>
            );
          })
        )}
      </ul>
    </div>
  );
}
```

Replace `src/components/combobox/combobox.tsx` with:

```tsx
import * as React from "react";
import { ChevronDown } from "lucide-react";
import { cn } from "../../lib/cn";
import { fieldSurfaceVariants } from "../../lib/field-surface.variants";
import { Popover, PopoverContent, PopoverTrigger } from "../popover";
import {
  ComboboxListbox,
  type ComboboxListboxItem,
} from "./combobox-listbox";
import type { ComboboxProps } from "./combobox.types";

const DEFAULT_PLACEHOLDER = "Select…";
const DEFAULT_EMPTY_MESSAGE = "No results";

function asArrayValue(v: string | string[] | null | undefined): string[] {
  if (v == null) return [];
  return Array.isArray(v) ? v : [v];
}

function findOptionByValue<T>(
  options: T[],
  getOptionValue: (o: T) => string,
  value: string,
): T | undefined {
  return options.find((o) => getOptionValue(o) === value);
}

function ComboboxImpl<T>(
  props: ComboboxProps<T>,
  ref: React.ForwardedRef<HTMLButtonElement>,
) {
  const {
    options,
    getOptionValue,
    getOptionLabel,
    isOptionDisabled,
    renderOption,
    multiple = false,
    value,
    defaultValue,
    onValueChange,
    placeholder = DEFAULT_PLACEHOLDER,
    emptyMessage = DEFAULT_EMPTY_MESSAGE,
    size = "default",
    state = "default",
    disabled = false,
    className,
    id,
    "aria-label": ariaLabel,
    "aria-describedby": ariaDescribedBy,
    "aria-invalid": ariaInvalid,
  } = props;

  const isControlled = value !== undefined;
  const [internalValue, setInternalValue] = React.useState<
    string | string[] | null
  >(() => {
    if (defaultValue !== undefined) return defaultValue;
    return multiple ? [] : null;
  });
  const currentValue = isControlled ? (value ?? null) : internalValue;
  const selectedValues = React.useMemo(
    () => asArrayValue(currentValue),
    [currentValue],
  );

  const [open, setOpen] = React.useState(false);
  const [activeIndex, setActiveIndex] = React.useState(0);

  const listboxId = React.useId();
  const optionIdPrefix = `${listboxId}-opt`;

  const items: ComboboxListboxItem<T>[] = React.useMemo(
    () =>
      options.map((option) => {
        const optionValue = getOptionValue(option);
        return {
          option,
          value: optionValue,
          label: getOptionLabel(option),
          selected: selectedValues.includes(optionValue),
          disabled: isOptionDisabled ? isOptionDisabled(option) : false,
        };
      }),
    [options, getOptionValue, getOptionLabel, isOptionDisabled, selectedValues],
  );

  const commitValue = React.useCallback(
    (next: string | string[] | null) => {
      if (!isControlled) setInternalValue(next);
      // Discriminated union: cast to the appropriate handler shape at runtime.
      if (multiple) {
        (onValueChange as ((v: string[]) => void) | undefined)?.(
          (next as string[] | null) ?? [],
        );
      } else {
        (onValueChange as ((v: string | null) => void) | undefined)?.(
          next as string | null,
        );
      }
    },
    [isControlled, multiple, onValueChange],
  );

  const handleSelectIndex = React.useCallback(
    (index: number) => {
      const item = items[index];
      if (!item || item.disabled) return;
      if (multiple) {
        const set = new Set(selectedValues);
        if (set.has(item.value)) set.delete(item.value);
        else set.add(item.value);
        // Preserve insertion order: only append new values to the existing list.
        const next = selectedValues.includes(item.value)
          ? selectedValues.filter((v) => v !== item.value)
          : [...selectedValues, item.value];
        commitValue(next);
      } else {
        commitValue(item.value);
        setOpen(false);
      }
    },
    [items, multiple, selectedValues, commitValue],
  );

  // Trigger label: resolve label from options; fall back to raw value when missing.
  const triggerContent = React.useMemo(() => {
    if (selectedValues.length === 0) {
      return (
        <span className="flex-1 truncate text-sm text-muted-foreground">
          {placeholder}
        </span>
      );
    }
    if (!multiple) {
      const v = selectedValues[0]!;
      const found = findOptionByValue(options, getOptionValue, v);
      const label = found ? getOptionLabel(found) : v;
      return <span className="flex-1 truncate text-sm">{label}</span>;
    }
    // Multi-mode chip rendering arrives in Task 5.
    return (
      <span className="flex-1 truncate text-sm">
        {selectedValues.length} selected
      </span>
    );
  }, [
    selectedValues,
    multiple,
    options,
    getOptionValue,
    getOptionLabel,
    placeholder,
  ]);

  const isEmpty = selectedValues.length === 0;

  return (
    <Popover
      open={open}
      onOpenChange={(next) => {
        if (disabled) return;
        setOpen(next);
        if (next) setActiveIndex(0);
      }}
    >
      <PopoverTrigger
        ref={ref}
        id={id}
        type="button"
        role="combobox"
        aria-haspopup="listbox"
        aria-expanded={open}
        aria-controls={listboxId}
        aria-label={ariaLabel ?? placeholder}
        aria-describedby={ariaDescribedBy}
        aria-invalid={
          state === "error" ? true : ariaInvalid
        }
        disabled={disabled}
        data-slot="combobox-trigger"
        data-state={state}
        data-placeholder={isEmpty || undefined}
        className={cn(
          fieldSurfaceVariants({ size, state }),
          "items-center justify-between gap-2 px-3 text-left",
          className,
        )}
      >
        {triggerContent}
        <ChevronDown
          aria-hidden="true"
          className="size-4 shrink-0 text-muted-foreground"
        />
      </PopoverTrigger>
      <PopoverContent
        align="start"
        sideOffset={4}
        className="w-(--radix-popover-trigger-width) min-w-60 p-0"
        onCloseAutoFocus={(e) => e.preventDefault()}
      >
        <ComboboxListbox<T>
          listboxId={listboxId}
          multiple={multiple}
          items={items}
          emptyMessage={emptyMessage}
          activeIndex={activeIndex}
          onSelectIndex={handleSelectIndex}
          optionIdPrefix={optionIdPrefix}
          renderOption={renderOption}
        />
      </PopoverContent>
    </Popover>
  );
}

export const Combobox = React.forwardRef(ComboboxImpl) as <T>(
  props: ComboboxProps<T> & { ref?: React.Ref<HTMLButtonElement> },
) => ReturnType<typeof ComboboxImpl>;

(Combobox as unknown as { displayName: string }).displayName = "Combobox";
```

```tsx
  const findNextEnabledIndex = React.useCallback(
    (from: number, dir: 1 | -1): number => {
      if (items.length === 0) return -1;
      let i = from;
      for (let n = 0; n < items.length; n++) {
        i = (i + dir + items.length) % items.length;
        if (!items[i]!.disabled) return i;
      }
      return -1;
    },
    [items],
  );

  const findFirstEnabledIndex = React.useCallback((): number => {
    for (let i = 0; i < items.length; i++) {
      if (!items[i]!.disabled) return i;
    }
    return -1;
  }, [items]);

  const findLastEnabledIndex = React.useCallback((): number => {
    for (let i = items.length - 1; i >= 0; i--) {
      if (!items[i]!.disabled) return i;
    }
    return -1;
  }, [items]);

  // When items change (e.g. after filtering), clamp the active index.
  React.useEffect(() => {
    if (items.length === 0) {
      setActiveIndex(0);
      return;
    }
    setActiveIndex((prev) => {
      if (prev >= items.length || items[prev]?.disabled) {
        return Math.max(0, findFirstEnabledIndex());
      }
      return prev;
    });
  }, [items, findFirstEnabledIndex]);

  const handleSearchKeyDown = React.useCallback(
    (event: React.KeyboardEvent<HTMLInputElement>) => {
      if (event.key === "ArrowDown") {
        event.preventDefault();
        setActiveIndex((prev) =>
          findNextEnabledIndex(prev, 1) === -1
            ? prev
            : findNextEnabledIndex(prev, 1),
        );
      } else if (event.key === "ArrowUp") {
        event.preventDefault();
        setActiveIndex((prev) =>
          findNextEnabledIndex(prev, -1) === -1
            ? prev
            : findNextEnabledIndex(prev, -1),
        );
      } else if (event.key === "Home") {
        event.preventDefault();
        const i = findFirstEnabledIndex();
        if (i !== -1) setActiveIndex(i);
      } else if (event.key === "End") {
        event.preventDefault();
        const i = findLastEnabledIndex();
        if (i !== -1) setActiveIndex(i);
      } else if (event.key === "Enter") {
        if (items.length === 0) return;
        event.preventDefault();
        handleSelectIndex(activeIndex);
      } else if (event.key === "Escape") {
        event.preventDefault();
        setOpen(false);
      }
    },
    [
      findNextEnabledIndex,
      findFirstEnabledIndex,
      findLastEnabledIndex,
      items,
      activeIndex,
      handleSelectIndex,
```

```tsx
type IOObserverEntry = {
  target: Element;
  callback: IntersectionObserverCallback;
  instance: IntersectionObserver;
};

const ioRegistry: IOObserverEntry[] = [];

class MockIntersectionObserver implements IntersectionObserver {
  readonly root: Element | Document | null = null;
  readonly rootMargin: string = "";
  readonly thresholds: ReadonlyArray<number> = [];
  private targets = new Set<Element>();
  constructor(private cb: IntersectionObserverCallback) {}
  observe(target: Element) {
    this.targets.add(target);
    ioRegistry.push({ target, callback: this.cb, instance: this });
  }
  unobserve(target: Element) {
    this.targets.delete(target);
    for (let i = ioRegistry.length - 1; i >= 0; i--) {
      if (ioRegistry[i]!.target === target && ioRegistry[i]!.instance === this) {
        ioRegistry.splice(i, 1);
      }
    }
  }
  disconnect() {
    for (let i = ioRegistry.length - 1; i >= 0; i--) {
      if (ioRegistry[i]!.instance === this) {
        ioRegistry.splice(i, 1);
      }
    }
    this.targets.clear();
  }
  takeRecords() {
    return [];
  }
}
```

## Cross-cutting notes

### Test environment

- `IntersectionObserver` is not provided by jsdom. The Task 7 test file installs a controllable mock locally — do not edit `src/test/setup.ts`.
- `userEvent.setup()` is used per-test, mirroring the date-picker tests.
- Radix portals their popover into `document.body`, so RTL's `screen.*` queries still find the listbox and options when the popover is open.

### Conventions reaffirmed

- All components use `data-slot="<name>"` for consumer styling hooks.
- The trigger uses `fieldSurfaceVariants` for visual parity with `Input`, `DatePicker`, `CurrencyInput`.
- Generic-with-accessors API mirrors `DataTable<T>`.
- ISO contracts: not applicable here (values are opaque strings the consumer assigns).
- Controlled / uncontrolled via `value` / `defaultValue` / `onValueChange`, matching `DatePicker` exactly.

### What this plan does NOT include

(Listed in the spec under "Out of scope".)

- Free-text "create new" entries.
- Async value→option resolver.
- Grouped options.
- Virtualized listbox.
- Tag-input style multi-select (no popover).
